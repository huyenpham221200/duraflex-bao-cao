# Báo cáo hằng ngày duraflex.com.vn

Mỗi ngày:
1. Tải 2 file báo cáo mới (`duraflex-danh-gia-DDMMYYYY-day-du.html`, `duraflex-danh-gia-DDMMYYYY-so-bo.html`) về thư mục Downloads.
2. Bấm đúp `cap-nhat.bat`.

Script chép file mới vào `nguon/`, dựng lại `index.html` (2 ngày gần nhất ở đầu trang, các ngày cũ ở mục "Xem lại các ngày trước") rồi đẩy lên GitHub Pages.
